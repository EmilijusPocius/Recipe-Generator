# Lamaistas Scraper (Archyvas)

Šiame aplanke yra kodas, skirtas `lamaistas.lt` duomenų surinkimui, ir gautas duomenų rinkinis (~25 000+ receptų).

Pradžioje bandžiau kurti lietuvišką receptų modelį, tačiau tokio duomenų kiekio neužteko kokybiškam apmokymui (modelis sunkiai mokėsi struktūros). Dėl šios priežasties pagrindiniame projekte pereita prie didesnio angliško `RecipeNLG` duomenų rinkinio.
